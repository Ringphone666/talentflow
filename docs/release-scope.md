# 作品集发布边界

该版本用于展示通用工程设计与项目实现，不包含任何实际组织的交付材料。

## 此版本保留

模块化平台代码、通用工作流、模型与语音适配、证据校验、人工复核、权限审计、文档生成和离线回归测试。

## 此版本不包含

原客户品牌和图片、原岗位资料及知识配置、原评审记录和验收附件、原环境地址、部署路由编号、旧系统迁移脚本、业务数据库、实际人员档案、实际录音、运行密钥，以及原项目 Git 历史。

## 替换与重建

- 使用 TalentFlow 独立命名、统一的环境变量前缀和通用品牌标识。
- 默认外部地址为不可访问的示例域名，凭据为空。
- 只提供明确标记为虚构的通用演示岗位与测试材料。
- PDF / DOCX 测试文件不直接存储在代码发布包中，从可审查的虚构文本重建。
- 公开说明以本版本代码和重新运行的测试为依据，不继承历史环境的性能或效果结论。

技术去标识化只描述本次文件处理范围，不替代对源代码公开权限的确认。公开可读与授予开源许可证是两个独立决定；本版本不自动附加 MIT / Apache 等授权。
